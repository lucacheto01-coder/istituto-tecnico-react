# Istituto Tecnico – React

## Descrizione del progetto

Progetto Front-End sviluppato durante il percorso formativo **Full Stack Web Developer presso Volta Institute**.

Il progetto consiste nella realizzazione di un'applicazione web dedicata a un istituto tecnico, sviluppata utilizzando **React** e un'architettura basata su componenti riutilizzabili.

L'obiettivo è mettere in pratica le conoscenze acquisite durante il corso, approfondendo lo sviluppo di interfacce web moderne e l'organizzazione del codice.

## Tecnologie utilizzate

- **React** – Sviluppo dell'interfaccia attraverso componenti.
- **JavaScript** – Gestione della logica applicativa.
- **HTML5** – Struttura dei contenuti.
- **CSS3** – Stile e presentazione grafica.
- **Webpack** – Compilazione e gestione delle risorse del progetto.
- **Node.js e npm** – Gestione delle dipendenze e degli strumenti di sviluppo.

## Struttura del progetto

- `src/` – Codice sorgente e componenti dell'applicazione.
- `public/` – Risorse pubbliche del progetto.
- `package.json` – Dipendenze e script disponibili.
- `package-lock.json` – Versioni delle dipendenze installate.
- `webpack.config.js` – Configurazione di Webpack.
- `tsconfig.json` – Configurazione TypeScript.

## Installazione

### 1. Clonare il repository

```bash
git clone https://github.com/lucacheto01-coder/istituto-tecnico-react.git
```

### 2. Accedere alla cartella del progetto

```bash
cd istituto-tecnico-react
```

### 3. Installare le dipendenze

```bash
npm install
```

### 4. Avviare il progetto

Consultare gli script presenti nel file `package.json` per individuare il comando di avvio o compilazione dell'applicazione.
